## Architecture decision ADR-001 (PROPUESTO)
Integrate additively around frozen KBS; do not rewrite `src/kbs_tech/core.py` or the M7 reserved task suite.
1. Shared contract layer: stable ids; epistemic status; evidence provenance; source validity; dependency edges; deterministic serialization and event ids.
2. ENTIDAD CORE adapter: nodes (entity/concept/claim/hypothesis/work item), typed relations (specialization/composition/association/dependency), explicit unknowns.
3. KBS adapter: translate external claim/evidence records into current `KBS` input without mutating the frozen implementation.
4. Discovery OS adapter: hypotheses, alternatives, counterexamples, falsifiers, reproducible experiment references; cannot self-promote hypothesis to fact.
5. Atlas adapter: WBS with input/dependencies/owner-function/deliverable/acceptance/evidence; schedules independent tasks without bypassing gates.
6. Audit and persistence: append-only verifiable execution events with versioned schemas; avoid shared mutable data between independent experiments.
7. End-to-end acceptance: problem → entities → atomic claims/evidence → rival hypotheses → experiment → verified result → dependent work item.

## Compatibility risk (INFERIDO)
`remove_source` checks only claims directly affected in a single event when identifying dependent inferences. Inference-to-inference transitive invalidation requires a distinct design decision and tests; changing RC1 silently is prohibited. Prefer a separate adapter whose closure computation is tested independently.
